# PDF Everything

一个基于 Vite + Preact + TypeScript 的纯前端 PDF 阅读器。无需后端，打开页面即可拖拽或选择本地 PDF 文件进行浏览。

重点解决三件事：

1. **大文档可用** —— 首屏快、滚动稳、内存可控（分批取页 + 视口懒渲染 + 虚拟滚动条）。
2. **渲染正确** —— 高分屏清晰、缩放不闪、pdf.js 配套资源（CMap / 字体 / wasm / ICC）齐全。
3. **交互完整** —— 文字可选中复制、链接可点、表单可填、页码/目录可跳转。

## 功能特性

### 打开与加载

- **本地文件打开**：拖拽到阅读区，或工具栏选择文件。
- **双重校验**：MIME + `%PDF` 文件头，改过扩展名的假 PDF 也会被拦下。
- **错误分类**：加密（可输密码解锁）、非法 PDF、未知错误分别提示。
- **加密 PDF**：原生密码输入弹窗，支持重试。
- **重选同一文件**：清空 input value，重复选择同一 PDF 也能重新加载。
- **按需资源**：CMap / 标准字体 / wasm / ICC 四类资源基址齐备，pdf.js 用到才 fetch 单个文件。
- **分批取页**：先取第 1 页定尺寸，其余每 24 页一批拉取；上千页不会一次发起上千个请求。
- **加载进度**：加载文档时显示百分比（流式未知大小时降级为已加载字节）；分批取页阶段用非阻塞的角标显示「已加载页 / 总页数」，不遮挡阅读区、不影响懒加载。
- **换文件即销毁**：销毁上一个文档与 worker，并用加载序号丢弃过期结果。

### 渲染与显示

- **高分屏适配**：canvas backing store 按 `devicePixelRatio` 放大，DPR 2 下依然清晰。
- **旋转**：工具栏左转 / 右转按钮，0°/90°/180°/270° 四档；文本层与注解层共用旋转后的 viewport，自动跟随对齐；**旋转后自动回到当前页**（≤2 页除外），避免视口漂移。
- **渲染取消**：缩放 / 换文件 / 卸载时 `cancel()`，不再出现 canvas 重复渲染警告。
- **文本层**：文字可**选中、复制**，与 PDF 内容精确对齐。
- **注解层**：**链接可点**（外链新窗口打开、内部链接跳到目标页）、**表单可填**（文本框 / 复选框 / 下拉），且**输入内容在缩放、翻页后保留**。
- **单页 / 双页**：一键切换布局，双页为居中两列网格；**超大页**（比多数页宽 > 10%，如折页/横版插页）在双页下**独占一行**、居中、加徽标突出，最多占两页宽，不破坏其他页排版。

### 导航

- **页码指示与跳页**：`‹ [页码] / N ›`，支持上一页 / 下一页；页码框可直接输入数字、按回车跳转，非法或越界输入回退到当前页。
- **当前页自动同步**：按「页面在视口中露出自身 ≥45%」判定，取达标页中页码最小者（进入 45%、退出 40% 的迟滞避免边界抖动）；候选为空时（页间空隙、高倍放大）退化为页顶偏移判定，保证页码不卡死。
- **目录**：树形 outline，可折叠，点击跳转。
- **虚拟滚动条（minimap）**：隐藏原生滚动条，自绘与文档高度成比例的滑块，支持拖拽 / 点击轨道 / 滚轮 / 键盘。
- **键盘导航**：方向键滚动 80px、`Page Up/Down` 滚动一屏、`Home/End` 跳首尾。

### 缩放

- `−` / `+` 按钮（25% 步长）、百分比输入框、`Ctrl` / `Cmd` + 滚轮（10% 步长），范围 50%–300%。

### 界面与体验

- **深色 / 浅色主题**：跟随系统初始化，可手动切换并记住。
- **中英文界面**：跟随浏览器语言，可手动切换并记住。
- **响应式布局**：窄屏下工具栏自动换行重排。
- **焦点管理**：属性弹窗打开即聚焦、Tab 循环限制在框内、Esc 关闭、关闭后焦点还原到触发按钮。
- **属性面板**：文件名、版本号、作者、主题、创建/生成工具、字体（行内最多 3 种，更多可弹窗，嵌入字体带标签）、创建/修改时间（hover 显示相对时间）、当前页 / 所有页尺寸（识别 A3/A4/A5/PA5/B4/B5/Letter/Legal，非标准尺寸双单位 pt+mm，可手动「计算所有页」）、页数、平均每页占用（键名 hover 提示计算口径）、线性化 / Fast Web View（键名 hover 提示说明）；支持一键复制为 INI（键名随界面语言）。

> 完整的行为细节、关键参数与设计取舍见 **[FEATURE.md](./FEATURE.md)**。

## 快速开始

环境要求：Node.js >= 20，pnpm >= 10。项目通过 `preinstall` 脚本强制使用 pnpm。

```bash
# 安装依赖
pnpm install

# 启动开发服务器（默认 http://localhost:5173）
pnpm dev
```

生产构建：

```bash
pnpm build        # 精简构建（默认）→ dist/，含 dist/pdfjs/ 资源目录
pnpm build-full   # 完整构建 → dist/，cmaps / wasm 全量
pnpm preview   # 本地预览
```

> `dist/pdfjs/` 由 `vite-plugin-static-copy` 在构建期从 `node_modules/pdfjs-dist` 拷贝，
> 不需要手工维护，也不会污染仓库。

### 两套构建产物

`vite.config.ts` 用 `--mode` 分两套，切换只影响 `dist/pdfjs/` 里拷多少资源，**应用代码完全一致**。

| | `pnpm build`（精简，默认） | `pnpm build-full`（完整） |
| --- | --- | --- |
| cmaps | 73 个（无竖排 `-V`、无历史遗留编码） | 168 个（全部） |
| wasm | `jbig2` / `openjpeg` / `qcms_bg` | 另含 `quickjs-eval` + 两个 `*_nowasm_fallback.js` |
| dist 体积 | 约 4.0 MB | 约 5.1 MB |

**默认用精简版的理由**：`.bcmap` 单文件只有几 KB，169 个里大部分是竖排 `-V` 变体和 1990 年代的编码；而 `quickjs-eval.wasm`(458 KB) 仅被 `pdf.sandbox.mjs` 与完整 viewer 使用，本项目的库入口对它 0 引用。

**什么时候需要 `build-full`**：

- 要打开竖排 PDF（日文小说、部分中文古籍）
- 要打开用 1990 年代编码（`78-*` / `90ms-*` / `Add-*` / `GBK2K-*` / `HK*` 等）的老 PDF
- 目标环境可能拿不到 wasm，需要纯 JS 兜底解码 JBIG2 / JPEG2000

## 实现要点

### 渲染策略：三段式

```
numPages（立即可知）
  → getPage(1)              定尺寸、出首屏
  → pageBatches(2, N)       每 24 页一批补齐其余页代理
  → IntersectionObserver    ≥10 页时视口内才渲染 canvas
```

未到达的页用**与首页同比例**的占位块撑住高度，使滚动高度从第一帧起就接近终值，滚动条不跳变。
懒加载阈值用**总页数**而非已加载页数，避免分批加载中途从 eager 翻到 lazy 造成重挂。

### 资源基址是"必须补"的

`getDocument` 必须给出 `cMapUrl` / `standardFontDataUrl` / `wasmUrl` / `iccUrl`（以 `/` 结尾、同源），
否则 PDF 用到非嵌入中文字体、JBIG2 / JPEG2000 图像或 ICC 色彩管理时会报错或降级。
补的是**基址**，不是把几百个文件提前下载——具体文件仍由 pdf.js 按需 fetch。

### 几何计算全部下沉为纯函数

`src/lib/` 下的 `pdfLayout.ts`、`pdfLoading.ts`、`pageNav.ts`、`interaction.ts` 都是无副作用函数，
组件只负责 DOM 与事件。因此滑块几何、滚动夹紧、分批切页、缩放与按键映射都能脱离浏览器做单元测试。

### 当前页判定：视口可见比例 + 最小页码

`IntersectionObserver` 以滚动容器为 root 观察全部 `.pdf-page-wrapper`，页面露出自身 ≥45% 进入候选、
<40% 移出（迟滞防抖），当前页取候选中页码最小者——与「页顶在视口上方的页就是当前页」的阅读直觉一致，单页/双页布局通用。

阈值只在跨越时回调，正常滚动时主线程不逐页读布局；候选集为空（页间空隙、超高页等）时才退回按页顶偏移反推，
保证极端缩放或空档下页码不卡死。取最小页号的计算下沉为 `pageNav.ts` 的 `minVisiblePage` 纯函数，可独立测试。

### 注解层是"叠加层"

`canvas` 负责外观，`TextLayer` 负责选择，`AnnotationLayer` 负责交互，三者共用同一 viewport。
`page.render` 使用 `AnnotationMode.ENABLE_FORMS`，把交互式表单交给注解层，避免画两遍。

## 已知限制

以下功能尚未实现，详见 **[PLAN.md](./PLAN.md)**：

- **无全文搜索**（`Ctrl+F`）与页面标签（罗马数字等）
- **worker 未复用**：换文件会重建 worker
- **`getDocument` 未调优**：`disableAutoFetch` / `maxImageSize` / `enableHWA` 等未设
- **无适配模式**（适合宽度 / 页面 / 实际大小）
- **无下载 / 打印**
- **移动端无手势**（双指缩放等）
- **不支持注释编辑**（`enableAnnotationEditing: false`）

缩略图侧栏**已决策暂不实现**，`ThumbnailSidebar.tsx` 仅保留类型骨架（无实现、无调用）。
